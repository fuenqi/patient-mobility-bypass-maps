# Data availability and confidentiality

The underlying BFS hospital microdata are confidential and are not included in this repository.

Do not add patient-level records, hospital identifiers, source extracts, intermediate data, or spreadsheets (including Excel workbooks) to this repository. The public materials contain only the interactive maps, region-year aggregates embedded in those maps, and simplified methodological code.

Access to the underlying data is governed by the applicable BFS data-access agreement and institutional requirements.
